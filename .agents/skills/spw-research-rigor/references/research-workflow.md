# Research Workflow (Rigor Lite)

Use this when you want “grad-school style” rigor without slowing down iteration.

## Evidence Standards

- Prefer falsifiable hypotheses over narrative claims.
- Define at least one negative control (what should not change).
- Record enough detail to reproduce: inputs, versions, commands, environment assumptions.

## Instrumentation Menu (Pick One)

- Timings (start/end, per phase, per rule)
- Counts (events, allocations, nodes, tokens)
- UI state transitions (mode/region/tab changes)
- Error rates / recovery events

## Structure

- Question
- Hypothesis
- Method (and controls)
- Results
- Interpretation
- Next experiments (ranked)

## Heuristics

- Keep experiments reversible.
- Prefer one variable changed at a time.
- If results are ambiguous, shrink the experiment or improve measurement.
