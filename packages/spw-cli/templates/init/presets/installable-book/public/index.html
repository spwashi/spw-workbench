Installable Book

Bookmarkable chapters, offline rails, and an upgrade path from plain file to rich publication.

This scaffold starts with plain HTML, a public directory, a service worker, and static JSON shaped like GET endpoints. It stays easy to edit, works offline after first visit, and leaves room for templates, a richer frontend, or a backend without changing the route contract. The .spw/ surface declares what the book is; the season layer controls how it looks.
