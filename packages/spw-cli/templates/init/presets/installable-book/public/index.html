Static site scaffold

Bookmarkable routes, readable pages, and an upgrade path to richer publishing.

This preset starts with plain HTML, a public directory, a service worker, and static GET-shaped JSON. It stays easy to edit with direct file changes, works offline after first visit, and leaves room for templates, a richer frontend library, or a backend without changing the route contract.

Offline and installable

Agent-readable
