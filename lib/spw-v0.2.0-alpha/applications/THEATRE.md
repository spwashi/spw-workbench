## v0.2.0 Contract Stub

`Theatre@` reinterprets Spw's operators through a dramatic performance lens. The same structural seed produces narrative semantics — `!` becomes an entrance, `?` becomes a dramatic question, `@` becomes an exit.

### Operator Reinterpretation

| Operator | Base meaning | Theatre@ meaning |
|----------|-------------|-----------------|
| `!` | Hydrate/inject | Entrance, action |
| `^` | Tap/anchor | Character naming |
| `~` | Defer/process | Recurring motif |
| `?` | Probe/query | Dramatic question |
| `=` | Config/bind | Character trait |
| `@` | Reference/emit | Exit, emission |

### Modifier Valence as Dramatic Register

| Modifier | Dramatic meaning |
|----------|-----------------|
| `boon` | Triumphant action |
| `bone` | Neutral direction |
| `bane` | Tragic action |
| `bonk` | Comic interruption |
| `honk` | Climax |

### Why This Lens Matters

`?` (probe) maps to "dramatic question" because it *is* the same cognitive operation: test a condition, branch on result. The mapping reveals that Spw's operators capture patterns shared between computation and narrative — both are structured decision-making.
